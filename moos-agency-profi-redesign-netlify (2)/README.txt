MOOS AGENCY — REVIZE (LISTOPAD 2026)

Web ve 4 HTML stranách, čisté HTML a CSS, bez JavaScriptu.
Připravený k přetažení do Netlify Drop. Soubor index.html je v kořeni ZIP archivu.

Vylepšení: vzdušná titulní strana, pečlivá práce se zlatými akcenty, CSS-only animace
při scrollu a při načtení, skutečné fotografie bez ořezu, vyvážená mřížka projektů,
role týmu s ikonami, výraznější kontakt. Bez dekorativních čar a linek.

Barevná paleta (definovaná v css/style.css):
  #FFFFFF bílá / hlavní pozadí
  #F7F5F0 teplá světlá / jemné plochy
  #EFEBE3 písková / závěrečné sekce
  #201D19 černá / hlavní text
  #625E57 neutrální / pomocný text
  #80602B hluboká zlatá / důležité akcenty

DŮLEŽITÉ:
Základní fotografie jsou původní doložené fotografie. Fotografie ze
sekce atmosféry v portfoliu jsou výslovně označené jako ILUSTRAČNÍ.
Narozeniny Duhovka café a Vánoční jarmark jsou uvedeny pouze textově,
dokud nebude k dispozici autentická fotografie.

Portréty týmu: v o-nas.html nahraďte zástupný obsah .team-portrait
obrázky <img src="assets/images/jmeno.jpg" alt="Portrét ...">.
CSS nastavuje object-fit:contain, takže se nic neořízne.

Animace jsou čisté CSS, při nepodporovaném prohlížeči zůstává obsah viditelný.
Respektována je systémová volba prefer-reduced-motion.
