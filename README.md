# MOOS Agency — Webová prezentace

Tento repozitář obsahuje rekonstruovaný a zoptimalizovaný statický web **MOOS Agency** postavený v čistém HTML5 a CSS3 (bez JavaScriptu a externích frameworků).

- **`website/`** — kompletní zdrojová struktura statického webu (`index.html`, `o-nas.html`, `nase-prace.html`, `kontakt.html`, modulární CSS v `css/`, optimalizované fonty/obrázky/loga v `assets/`, `robots.txt`, `sitemap.xml`, `README.md`).
- **`moos-agency-website.zip`** — finální produkční ZIP archiv připravený k okamžitému nasazení na běžný statický webhosting nebo přes Netlify Drop (`index.html` se nachází přímo v kořeni ZIP archivu).

Podrobnou technickou dokumentaci najdete v `website/README.md`.
